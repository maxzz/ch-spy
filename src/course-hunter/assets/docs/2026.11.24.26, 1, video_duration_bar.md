**User**

At the end of each row, the video time length for that specific element is displayed. 
In the column showing these time length, a small bar should be added beneath each time value. 
This bar represents the total duration of all video elements combined. 
Within this bar, a darker-colored rectangle should indicate the specific position and duration of the element in question relative to the entire video (as sum of all elements duration). 
In other words, the bar as a whole represents the total duration of all elements, while the rectangle within it shows the placement and size of the individual element. 
These values should be calculated as percentages; since the duration of elements in the list have fixed, static durations, these calculations only need to be performed once and can then be reused as needed. The provided screenshot illustrates how this bar should look.

I added a small duration bar under each row's time value. I haven't run the app or looked at it in a browser, so the visual result is untested.

- **Calculation (`store/a-derived.ts`):** a new derived atom, `durationBarsAtom`, turns each item's `HH:MM:SS` duration into seconds and computes its `left` offset and `width` as percentages of the total. It depends only on `itemsAtom`, so it is computed once per items list and reused by every row.
- **Rendering (`components/2-main/3-part1-playable-items.tsx`):** each row renders a light track under the time value, with a darker blue rectangle placed at that item's `left` and sized to its `width`. The link is now a flex column so the bar sits directly under the time text.

The colors are my pick (light blue track, the existing `#1985ff` blue for the segment), since the screenshot's exact colors weren't specified. Adjust them in the `className` if you want a different look.
