# Scrollbar thumb adjustments
_Exported on 11/25/2026 at 14:03:57 PST from Cursor (3.32.4)_

---

**User**

In the shadcn scrollable area, the scrollbar thumb blends in too much with the background; the thumb's color needs to be made slightly darker, and the thumb itself should be made a bit narrower.

---

**Cursor**

I updated the shadcn scroll area in `src/ui/shadcn/scroll-area.tsx`. I haven't run the app to check how it looks.

- **Color:** the thumb was `bg-border`, which is very light in light mode (`oklch(0.922)`) and only 10% white in dark mode. It now uses `bg-muted-foreground/40`, which is noticeably darker in both themes.
- **Width:** the track went from `w-2.5` to `w-2` (vertical) and from `h-2.5` to `h-2` (horizontal). With the existing `p-px` padding, the thumb is now 6px instead of 8px.

The track is also narrower, so the scrollbar takes 2px less space. If you want the layout footprint kept as it was, I can leave the track at its old size and add extra padding to thumb only. The `/40` opacity is also a starting point; if it still looks too faint, `/50` or `/60` would be the next step.
