Узнайте, как создать приложение админки с помощью Vue 3. В этом курсе: Vue 3, Nuxt.js, Composition API, Options API, Vuex, Typescript, Docker, c3.js charts, Загрузка Изображений, Экспорт CSV, Stripe.


В этом руководстве вы узнаете как:

  • Использовать Vue с Typescript;
  • Использовать Nuxt.js;
  • Использовать Vuex;
  • Как использовать Composition API и Options API;
  • Создавать классы, интерфейсы;
  • Создавать общедоступные и частные маршруты;
  • Ограничить маршруты для неавторизованных пользователей;
  • Загрузить изображения;
  • Экспортировать CSV;
  • Создать диаграмму с помощью c3.js (часть d3.js);
  • Оплачивать с помощью Stripe;

Если это то, что вы ищете, то этот курс для вас.
